# Hive press pack

Start with [the v1 visual guidelines](v1/README.md), then open
[the local asset catalogue](v1/index.html) or [the brand board](v1/previews/brand-board.png).
This is the September 2026 PocketHive Press Set, preserved as the original edition.
It contains visual instructions, palette and typography tokens, editable compositions,
logos, icons, badges and illustration assets. It is not the `@pockethive/ui` component library.

## Source and scope

Recovered from the user-provided `PocketHive-Press-Set-v1.zip` archive, with publication
explicitly requested by the project owner. The versioned files are preserved unchanged.
The original provenance and generation prompts are in `v1/README.md` and `v1/PROMPTS.json`.
The logo derives from PocketHive `ui-v2/public/logo.svg`; illustrations were generated
from user-supplied references. No original conversation exports, credentials, private
reference files, runtime data or ZIP duplicate are included.

The repository LICENSE remains applicable; this package does not grant additional
trademark rights or rights to third-party source references. The archive contains no
separate asset license notice. Preserve the provenance when reusing these materials.

## Applying the direction to an application

Use the authoritative palette and font in `v1/tokens.json` and the visual guidelines
in the versioned README. The kit describes presentation compositions, not an application
component or accessibility specification. Slide dimensions and safe margins do not
replace responsive application layout rules. Business badges and delivery labels are
independent; they must not automatically imply feature availability or task status.
