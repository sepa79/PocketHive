# HiveForge Release Deploy Handoff

This is a historical handoff from the early repository/ref deployment bridge.
Its former build-in-deploy instructions and incomplete runtime examples have
been superseded by [PocketHive installation with HiveForge](HIVEFORGE.md).
Use that guide for supported profiles, complete runtime configuration, MCP
installation/update steps and verification.

Image publication remains separate from deployment and is documented in
[GHCR Setup](GHCR_SETUP.md). Required version-to-version actions are indexed in
[Upgrading PocketHive](UPGRADING.md).

The earlier implementation history is retained in Git. This page is not a
second installation procedure or a statement of current deployment support.
